# Яндекс.Диск — публичная ссылка на текущую папку

Расширение помогает копировать публичную ссылку на текущую папку Яндекс.Диска. Сохраните публичную ссылку на папку как корень, затем открывайте её вложенные папки — расширение добавит путь к сохранённой ссылке.

## Возможности

- Формирует ссылки для папки и её вложенных папок на основе сохранённого корня. Если подходит несколько корней, выбирается корень с наиболее длинным совпадающим путём.
- Копирует ссылку из кнопки попапа или горячей клавишей.
- Копирует ссылку и открывает её в новой активной вкладке.
- Сохраняет корень кнопкой в попапе: расширение попросит вставить публичную ссылку для открытой папки.
- Показывает панель сохранения при распознавании окна «Поделиться». Панель предлагает сохранить ссылку для текущей или выбранной папки, принимает вставку через Cmd/Ctrl+V и Enter, а также закрывается по Escape.
- Может закрывать панель сохранения автоматически через 10 секунд. Автозакрытие включено по умолчанию и настраивается в попапе.
- Показывает сохранённые корни в попапе; их можно переименовать, удалить или открыть публичную ссылку в новой вкладке.
- При обнаружении папки с тем же родительским путём и новым именем пробует обновить имя последнего сегмента сохранённого корня.

## Установка из исходников

1. Скачайте или клонируйте репозиторий.
2. Откройте страницу расширений браузера: `chrome://extensions` (в Яндекс Браузере — `browser://extensions`).
3. Включите режим разработчика.
4. Нажмите «Загрузить распакованное расширение» и выберите папку `Main`, содержащую `manifest.json`.

В манифесте используется Manifest V3. Установка из магазина расширений в этом репозитории не описана.

## Как пользоваться

### Сохранить корень

Откройте папку, на которую создана публичная ссылка, и нажмите в попапе «Запомнить корень». Вставьте публичную ссылку в появившийся запрос.

Либо откройте меню «Поделиться» у папки. Если расширение распознает окно, появится панель сохранения. Вставьте публичную ссылку через Cmd/Ctrl+V или вручную и нажмите «Сохранить» (можно нажать Enter).

Сохраняйте ссылку именно для папки, которая указана как корень. Если сохранить ссылку для другой папки, ссылки будут строиться относительно неё. При отсутствии подходящего сохранённого корня горячая клавиша покажет уведомление об ошибке; автоматически предложить сохранить корень в этот момент расширение не может.

### Скопировать ссылку на папку

Откройте нужную папку в Диске и нажмите кнопку «Скопировать ссылку» в попапе или горячую клавишу. Для второго действия расширение скопирует ссылку и откроет её в новой активной вкладке.

### Горячие клавиши по умолчанию

| Действие | Windows / Linux | macOS |
|---|---|---|
| Скопировать публичную ссылку | Ctrl+Shift+Y | Command+Shift+Y |
| Скопировать ссылку и открыть её | Ctrl+Shift+O | Command+Shift+O |

Сочетания заданы в манифесте как предлагаемые по умолчанию. Браузер может позволить изменить их на странице настроек сочетаний клавиш расширений.

## Поддерживаемые адреса

Расширение подключает сценарий и обрабатывает страницы HTTPS на следующих доменах:

- `disk.yandex.ru`
- `disk.yandex.com`
- `disk.360.yandex.ru`
- `yadi.sk`

Для сохранённой публичной ссылки принимаются адреса этих доменов с путём `/d/...`. Путь к текущей папке считывается со страниц вида `/client/disk/...`.

## Данные и разрешения

- Сохранённые корни (публичная ссылка, путь и название) хранятся в `chrome.storage.local`; они не синхронизируются этим расширением между устройствами.
- При первом обращении, если в локальном хранилище ещё нет массива корней, расширение переносит старый массив из `chrome.storage.sync` в `chrome.storage.local`.
- Настройка автозакрытия панели хранится в `chrome.storage.sync`.
- Разрешения манифеста: `activeTab`, `scripting`, `storage`, `clipboardRead`. Список сайтов для доступа приведён выше.
- Буфер обмена читается, когда пользователь вставляет ссылку сочетанием Cmd/Ctrl+V в панели сохранения. Сохранённые ссылки используются для формирования ссылок на подпапки.
- Код проекта не отправляет сохранённые корни на собственный сервер. Ссылки Telegram и поддержки открываются по нажатию пользователя в попапе; также открываются публичные ссылки, выбранные или сформированные пользователем.
